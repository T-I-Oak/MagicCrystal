バックログには詳細な要件が記載されていません。

Magic Crystal はフレーム単位の挙動で成立するパズルゲームです。
開発時は [開発運用ルール](../specifications/development_rules.md) のゲームエンジン保護ルールを遵守し、キャラクターの移動・ジャンプ・落下・当たり判定・入力反映タイミングを変更しないでください。

## オーナー検証

- [ ] Stage Select の機能選択UIを確認する
    - `PLAY` / `SETTINGS` が画面下部の機能選択として表示されること。
    - スマートキーで機能選択、決定キーで選択ステージに対して機能実行できること。
    - ステージをタップした場合、未選択ステージは選択のみ、選択済みステージは選択中の機能を実行すること。
    - `SETTINGS` から戻ったとき、背景が Stage Select 画面であること。

- [ ] Extra Map の機能選択UIを確認する
    - `PLAY` / `EDIT` または `CREATE` / `COPY` / `PASTE` / `SHARE` / `FAVORITE` または `UNFAVORITE` / `DELETE` が画面下部の機能選択として表示されること。
    - `SHARE` が2段目に表示され、左右スマートキーの位置が自然であること。
    - スマートキーで機能選択、決定キーで選択スロットに対して機能実行できること。
    - スロットをタップした場合、未選択スロットは選択のみ、選択済みスロットは選択中の機能を実行すること。
    - `BACK` は短押しでタイトルに戻ること。

- [ ] Extra Map の保持マップ操作を確認する
    - 空スロットで `CREATE` を実行すると編集画面へ遷移すること。
    - `CREATE` 後に `DISCARD` した場合、対象スロットが `EMPTY` のまま残ること。
    - お気に入りのオン/オフでハートアイコン表示が切り替わること。
    - `DELETE` 実行時に削除確認モーダルが表示され、`CANCEL` で保持マップが残ること。
    - 削除確認モーダルで `DELETE` を選ぶと対象スロットが `EMPTY` に戻ること。
    - お気に入り設定された保持マップでは `DELETE` が無効表示され、実行しても削除されないこと。

- [ ] Extra Map のプレイを確認する
    - Extra Map のプレイ時、表示が `EXTRA STAGE N` になること。
    - Extra Map のプレイ時、残り人数が常に1になること。
    - Extra Map のプレイ後にギャラリーへ戻ること。

- [ ] Editor Mode の機能選択UIを確認する
    - 画面下部に `HELP` / 地形選択 / `DIFFICULTY` / `SAVE` が機能選択として表示されること。
    - `HOLD B DISCARD` が機能選択の外側に表示されること。
    - デフォルト機能が `HELP` で、決定すると `HOW TO EDIT` が表示されること。
    - スマートキーで機能選択、決定キーで機能実行できること。
    - 地形選択中に決定すると、現在座標へ選択中の地形を配置できること。
    - フルキー `0` から `7` で、対応する地形の選択と配置を同時に実行できること。

- [ ] Editor Mode のタップ操作を確認する
    - 未選択の機能をタップした場合、その機能が選択されるだけで実行されないこと。
    - 選択済みの機能をタップした場合、その機能が実行されること。
    - 未選択の編集座標をタップした場合、編集カーソルが移動するだけで地形配置されないこと。
    - 選択済みの編集座標をタップした場合、地形選択中のみ地形配置されること。
    - 地形選択以外の機能選択中に編集座標をタップしても、`HELP` / `DIFFICULTY` / `SAVE` が誤実行されないこと。

- [ ] Editor Mode の難易度設定を確認する
    - `DIFFICULTY` を実行すると難易度設定モーダルが表示されること。
    - 難易度設定モーダルのタイトルが `DIFFICULTY SETTINGS`、項目名が `DIFFICULTY` として表示されること。
    - 難易度設定モーダルの枠、タイトル、項目名、選択マーカー、値変更UI、`B CLOSE` 表示が通常の設定画面と共通の見た目であること。
    - 難易度説明文が表示領域内に収まり、他のモーダルと比較して違和感がないこと。
    - 値行にカーソルがあるときだけ左右で難易度を変更できること。
    - 選択可能な最高難易度を超える値には変更できないこと。
    - 左右で変更した難易度が即時に編集セッションへ反映され、`B CLOSE` でモーダルだけ閉じること。
    - 難易度のみを変更して `SAVE` した場合、クリアーステータスが維持されること。
        - Extra Map のクリアー可能導線が揃うまで確認保留。
    - ステージ内容を変更して `SAVE` した場合、クリアーステータスが未クリアに戻ること。
        - Extra Map のクリアー可能導線が揃うまで確認保留。

- [ ] モーダル表示と操作の統一感を確認する
    - Extra Map の削除確認モーダルで、背景、枠、タイトル、本文、`A DELETE` / `B CANCEL` ボタンの表示に違和感がないこと。
    - Extra Map の空きスロットなしモーダルで、背景、枠、タイトル、本文、`B CLOSE` ボタンの表示に違和感がないこと。
    - 共有URLの読み込み失敗画面で、背景、枠、タイトル、本文、`B CLOSE` ボタンの表示に違和感がないこと。
    - タイトル画面または Stage Select から開いた設定画面で、設定項目を変更でき、`B CLOSE` で閉じる表示と操作に違和感がないこと。
    - Editor Mode の難易度設定モーダルで、背景、枠、タイトル、設定項目、`B CLOSE` ボタンの表示に違和感がないこと。
    - Map Share の共有確認モーダルで、タイトル、本文、`A OPEN X` / `B CLOSE` ボタンの表示と操作に違和感がないこと。
    - 上記モーダルの `A` / `B` キーフェイス位置が、それぞれのボタン内で文字と重ならず自然に揃っていること。
    - 上記モーダルの表示中に、背後のステージ選択、Extra Map、Editor Mode の操作が誤発火しないこと。

- [ ] `HOW TO PLAY` / `HOW TO EDIT` の表示と操作を確認する
    - `HOW TO PLAY` の操作キー定義と対応表が分かりやすいこと。
    - `HOW TO EDIT` が `HOW TO PLAY` の操作キー定義を前提に、編集操作だけを説明していること。
    - どちらも上下キー、ドラッグ、ホイールで最後までスクロールできること。
    - 戻るボタンの表記と位置に統一感があること。

- [ ] Map Share の導線を確認する
    - クリア済みの Extra Map のみ `SHARE` できること。
    - 共有文言が日本語/英語で意図通り表示されること。
    - 共有文言に難易度が `難易度: ★★` / `Difficulty: ★★` の形式で含まれること。
    - 共有画像から難易度表示が除かれていること。
    - 共有画像で copyright がマップと重ならず、マップ外に表示されること。
    - 共有画像でポータル位置にキャラクターがオーバーレイ表示されること。
    - PCでは画像がクリップボードにコピーされ、確認モーダルからXを開けること。
    - 共有確認モーダルでキーボード操作ができ、移動キーが背後の画面に伝わらないこと。

- [ ] 共有URLからの Extra Map 読み込みを確認する
    - `?map=` の共有URLを開くと、正しいマップが読み込まれてプレイ対象になること。
    - 既存マップと同一データの場合、新規保存せず既存スロットをプレイ対象にすること。
    - 同一データ判定時に既存スロットの難易度が変更されないこと。
    - 空きスロットがない場合、Extra Map 画面に遷移してから「マップに空きがないためダウンロードできませんでした。マップに空きを作ってからダウンロードしなおしてください。」相当の通知が表示され、保存されないこと。
    - 不正な `map` の場合、読み込み失敗画面が表示されること。

- [ ] コピー/ペーストを確認する
    - コピー済みステージがない状態では `PASTE` が無効表示になり、実行しても保持マップが作成されないこと。
        - コピー機能の確認導線が揃うまで確認保留。
    - 上限より高い難易度のマップをコピーしてペーストした場合、コピー元の難易度は変更されないこと。
    - ペースト先の難易度はプレイヤーが設定可能な最高難易度を上回らないこと。
